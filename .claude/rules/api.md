# API rules (auto-loaded)

- FastAPI + SQLAlchemy 2 (async) + Alembic + pydantic v2. Python 3.12 in Docker. Tooling: `uv`, `ruff`, `pytest`.
- Every request/response model has a matching zod schema in `packages/api-contracts`; regenerate types with `pnpm contracts:gen` (openapi-typescript) after changing routes.
- Scheduler = `arq` worker on Redis. Cron jobs live in `services/api/app/worker.py`. No Celery.
- Migrations are autogenerated then reviewed; never edit applied migrations.
- Dev OTP is always `123456` when `OTP_DEV_MODE=true`. No SMS provider in this phase.
- Secrets from `.env` only; commit `.env.example`.
- Docker (F-27): `pnpm docker:up` runs the whole app — `web` (Expo static export behind nginx) on http://localhost:3201, `api` on http://localhost:8200 (uvicorn on 8000 inside, `--reload` over the bind mount), `worker`, postgres:17 on 5432, redis:7 on 6379. No compose profiles. `pnpm api:up` starts only `postgres redis api worker`; `pnpm api:migrate` = `alembic upgrade head` in the container. Host ports are `WEB_HOST_PORT` / `API_HOST_PORT` / `POSTGRES_HOST_PORT` / `REDIS_HOST_PORT`; the api `CORS_ORIGINS` default follows `WEB_HOST_PORT`, the web image bakes `EXPO_PUBLIC_API_URL` from `API_HOST_PORT` (rebuild `web` after changing it).
